# Beacon v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Beacon v1, a macOS menu bar app that finds, points and marks up with the cursor during full-screen screen sharing, with polished cursor skins.

**Architecture:** A Swift package `BeaconCore` holds all logic (recognizers, models, effects, overlay management) behind small protocols; a thin XcodeGen app target `Beacon` hosts the menu bar item, popover and settings window. One click-through overlay window per display hosts Core Animation layers for skin, halo, laser, pulse and ink. The cursor-hide mechanism is chosen by a gating spike (Task 0) and isolated behind `CursorHider`.

**Tech Stack:** Swift 6, SwiftUI (settings, popover), AppKit and Core Animation (overlays), XcodeGen, Sparkle 2, XCTest.

**Spec:** `docs/superpowers/specs/2026-11-08-beacon-v1-design.md` (read it with this plan). Reference code to port and adapt: `~/Personal/Projects/Veil` (overlay windows, shake recognizer, Sparkle, settings), `~/Personal/Projects/Perch`, `~/Personal/Projects/Cue` (Apropos).

## Global Constraints

- Swift 6, SwiftUI plus AppKit, macOS 14.6+, universal binary.
- Menu bar agent (LSUIElement), no Dock icon, no tabs, no document windows.
- Direct distribution, Sparkle updates, Homebrew cask. No licensing code, no analytics; network only for the update check.
- Private API only behind a protocol with a public fallback, in one isolated folder (`Sources/BeaconCore/Private/`).
- No Accessibility or Screen Recording permission unless a feature truly needs it, and then optional. Input Monitoring is optional; without it shake works and Ink is a toggle on a Carbon hotkey.
- All branding lives in `Sources/BeaconCore/Branding.swift` and the asset catalog. The name "Beacon" is a placeholder.
- No emojis in code. No force casts, no force unwraps in production code. French text uses real UTF-8 characters.
- Core logic in the package and unit-tested; views thin.
- Commit subjects are lowercase `feat:` / `fix:` / `chore:`, no attribution lines. Stay on the checked-out branch.
- Never launch, kill or reinstall the author's running copy. Visual checks use an agent-mode build (`BEACON_AGENT=1`).
- Anything needing the real desktop (multi-display, Stage Manager, real Zoom, Meet, Teams) is reported as not verified.
- v1 cursor look is the system cursor size plus effects around the real cursor (spec section 4.3, revised 2026-11-11). Custom cursor arrows are a later research task.

## Review Focus

1. Quit, crash or force-quit while the cursor size is changed: the original size must come back (restore on quit, and a relaunch restore from a persisted marker). Pinned in Task 4.
2. A display is unplugged or the Mac sleeps while an effect is on screen: no stale or orphaned windows, no stuck state. Pinned in Task 2.
3. Degenerate Ink input: a single click, a zero-length stroke, a stroke of two points. No crash, no shape. Pinned in Task 8.
4. Triggers overlapping: shake while Ink is held, double-tap Option during Laser. One effect wins deterministically and nothing sticks on. Pinned in Task 9.
5. Mixed-scale displays (Retina plus non-Retina): halo and effects stay centered on the real pointer position. Pinned in Tasks 5 and 6.
