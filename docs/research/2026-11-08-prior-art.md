# Prior art (researched 2026-11-08)

Sources are vendor pages, App Store listings and forums, so feature lists are unverified.

| Tool | Does | Gap |
|---|---|---|
| Mouseposé (Boinx) | Spotlight that dims around the cursor, click and keystroke display, hotkey | Dated look, presenter-only |
| Mouzz, Mouse Pro, FocusCursor, CursorFlow, CursorRipple, Highlight My Cursor | Halo, ring, click ripple, magnifier, trails, some drawing | Many small single-purpose utilities, generic look |
| Presentify, DemoPro, Epic Pen, MarkerOn | Draw on screen with hotkey, laser pointer, click-through mode | Ink stays until cleared, plain effects |
| Screen Studio | Smoothed cursor path, larger cursor, motion blur, auto-zoom, spring settings | Recording only |
| Zoom Spotlight / Annotate | Built-in pointer tools | Sharer-only; cursor often hidden when sharing a single window (known limitation) |
| Figma, Miro, ClickUp | Figma: multiplayer cursors and cursor chat. Miro: no laser pointer. ClickUp: requests for a visible pointer in screen shares | Nobody has built the viewer-side pointer well |

## Gaps Beacon targets
1. No tool combines find, point and mark up well.
2. Nobody treats the cursor as a design product.
3. Window-share capture of overlays is unsolved; needs a spike.
